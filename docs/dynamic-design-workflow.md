# Dynamic Design Workflow User Guide

This step-by-step guide explains how to design, test, save, and manage custom 3D physical construction models in the PuzzleCore platform without ever touching local JavaScript source files.

---

## 1. Creating a New Model (+ New Button)

1. Navigate to the Assembly Workbench (`index.html`).
2. In the top navigation bar, click the **+ New** button (located right next to the active model selector, and also on the right action bar).
3. A modal dialog will appear:
   * **Model Name**: Type the name for your model (e.g. `Modern Villa 1`, `Football Court 2`, `Tiger 1`).
   * **Starter Template**: Choose a starting base (e.g. `Minimal Box (4 Parts) — Recommended`, or `Clean Blank Structure`).
4. Click **⚡ Create & Try Model** (or press `Enter`).
5. The Code Studio drawer slides open immediately with new, customized JavaScript code reflecting your model's name and unique ID, and automatically triggers **Live Preview** ("try it") so your new model appears in the 3D viewer instantaneously!

---

## 2. The In-Browser Code Studio

You can also open or toggle the Code Studio at any time by clicking **⚡ Design Studio**:
* **Direct Name Editing**: Edit your model's name directly in the header input box of the Code Studio at any time.
* **Load Templates**: Switch templates using the template picker dropdown.
* **Paste External Code**: Paste custom JavaScript models generated by AI or CAD converters directly into the code editor.
* **Try Model (Preview)**: Click the green **▶ Try / Live Preview** button or press **`Ctrl + Enter`** to re-render in real-time.

---

## 3. Live 3D Preview (Instant Feedback)

* Click the green **▶ Live Preview** button or press **`Ctrl + Enter`** (`Cmd + Enter` on macOS).
* The client-side sandbox parses your code, audits the geometry, and renders the extruded 3D model into the active Three.js canvas in real-time.
* The parts list on the left sidebar, assembly steps scrubber at the bottom, and camera sightlines update automatically.

### Handling Diagnostic Errors
If your code contains syntax errors or missing required fields:
1. A **red diagnostic banner** will appear at the bottom of the editor.
2. The banner indicates the exact **Line & Column** where the problem occurred.
3. Clicking the **Line badge** immediately jumps the editor cursor to the affected line.
4. Review the **Suggested Fix** for guidance (e.g. adding a comma, closing a bracket, or renaming duplicate part IDs).

---

## 4. Saving & Versioning Designs

* Click **💾 Save** to save changes to the current design.
* Click **Save As...** to branch the design into a new version or independent model (e.g. *Football Court 2*).
* A modal prompts you for:
  * **Design Name**: (e.g. `Grand Olympic Stadium`)
  * **Category**: (e.g. `Sports Architecture`)
  * **Description**: (e.g. `Added high-capacity tiered seating wings`)
* The system automatically generates a preview thumbnail from your 3D canvas and stores the design in **Google Cloud Firestore** and local browser cache.

---

## 5. Managing Stored Designs ("My Designs")

Click **☁️ My Designs** in the navigation bar to open the Cloud & Local Design Browser:
* **Search & Filter**: Search by design name or filter by category.
* **Visual Cards**: View preview thumbnails, part counts, dimensions, and version badges.
* **Actions**:
  * **▶ View**: Switches the active 3D assembly to this model immediately.
  * **✏️ Edit**: Loads the design's JavaScript code into the Code Studio.
  * **Duplicate**: Clones the design with a new title.
  * **Export .JS**: Downloads a clean, standalone `.js` file to your computer.
  * **Delete**: Removes the design from cloud and local storage.
